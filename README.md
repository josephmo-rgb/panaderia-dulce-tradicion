# Panadería Dulce Tradición

Sitio escolar sobre panadería mexicana, hecho con HTML, CSS y JavaScript sin dependencias.

## Contenido

- Catálogo de 20 panes con precios y buscador.
- Arma tu caja: selecciona cantidades y calcula el total estimado.
- Reto panadero: cinco preguntas con explicaciones y resultado.
- Combinaciones: elige una bebida y encuentra panes para acompañarla.
- Diseño adaptable a celulares y animaciones que respetan la preferencia de reducir movimiento.

## Abrir en tu equipo

Descarga el proyecto, extrae la carpeta y abre `index.html` en tu navegador. No necesitas instalar paquetes ni iniciar un servidor.

Para editar, abre la carpeta completa en Visual Studio Code. Conserva los archivos HTML junto con la carpeta `assets`.

## Archivos

```text
index.html
caja.html
reto.html
combinaciones.html
assets/
  estilos.css
  sitio.js
  actividades.js
```

El contenido principal está en `index.html`; las otras páginas comparten el diseño y el JavaScript correspondiente desde `assets`.

Las imágenes conservan los enlaces externos del proyecto original y requieren conexión a internet. Las actividades funcionan localmente y no envían pedidos ni procesan pagos.
